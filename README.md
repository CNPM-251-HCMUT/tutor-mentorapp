**Để chạy backend**

1/ CD đến folder BE

2/ python -m venv venv (nếu chưa có venv)

3/ venv/Scripts/activate

4/ pip install requirement.txt (nếu chưa cài thư viện)

5/ py main.py để chạy backend



**Để chạy FE**

1/ cd đến FE

2/ npm run dev để chạy (nó sẽ hiện cổng localhost, mình nhấn vào)

**Gọi API**

các api được lưu trong FE/src/pages/service/api.ts
